## Data flow

- כל דף = עותק תבנית עם `data-slug` על `<html>`; מרנדר לתוך `<main id="artist-root">`.
- דאטה: `<script src="../../data/generated/{artists,art-works,ex-statements,ex-order}.js">` (globals `__ARTISTS_INLINE__`/`__ART_WORKS_INLINE__`/`__EX_STATEMENTS_INLINE__`/`__EX_ORDER_INLINE__`), file:// + http; fallback `fetch("../../data/artists.json")`.
- **🔴 שינוי דאטה = לערוך JSON → `python3 tools/sync_data.py`.** לעולם לא להדביק דאטה לדף אומן ולא לערוך את `data/generated/*`. `--check` נכשל על עותק inline שחזר (`<script id="…-inline">`) או על `<script src>` חסר (`artists.js`+`art-works.js` תמיד; +`ex-statements.js`+`ex-order.js` בכל דף עם `buildExGroups`).
- 🔴 `__ARTISTS_INLINE__` הוא אובייקט `{…,"artists":[…]}` — הרנדרר מפרק `.artists` לפני הבדיקה; לא להסיר (בלעדיו "ARTIST NOT FOUND" ב-file://).
- בדיקה ויזואלית/טיפוגרפית רק ב-http (ב-file:// הפונטים חסומים). אבל 🔴 **טעינת דאטה חייבת להיבדק גם ב-file://**: ב-http, `artists.js` חסר או שבור נבלע ע"י `fetch("../../data/artists.json")` והדף נראה תקין — שני באגים היסטוריים (`.artists`, שבירות-שורה גולמיות בתוך מחרוזות JS) נשברו רק ב-file://. `tools/regress/snapshot.mjs` בודק ב-http וגם ב-file://, ו-`sync_data.py --check` תופס עותק stale או `<script src>` חסר.
- 🔴 **שינוי ביו / שם / פורטרט / אינסטגרם של אומן קיים:** `sync_data.py` מעדכן רק את הרינדור. הראש של `artists/<slug>/index.html` מחזיק העתקים סטטיים — לעדכן ידנית באותו קומיט (תקדים jessica-tabarovsky 2026-07-06):
  - **ביו** → `<meta name="description">` (מחוץ לבלוק SEO:auto), `og:description`, `twitter:description`, JSON-LD `Person.description`.
  - **שם** → `<title>` (מחוץ לבלוק), `og:title`, `twitter:title`, `og:image:alt`, JSON-LD `ProfilePage.name` + `Person.name`/`alternateName` + שם הפריט ב-`BreadcrumbList`.
  - **פורטרט** → לאפות מחדש `og/artists-<slug>-<שם קובץ הפורטרט>.jpg` (ראה צ'קליסט "אומן חדש"), ולעדכן `og:image`, `twitter:image`, `og:image:width`/`height` (מידות הקובץ החדש) ו-`Person.image` — שמצביע בחלק מהדפים ל-`portrait.webp` (gal-rotem) ובחלק ל-OG jpg (aharon-bas, hadas-tuval, amnon-lipkin): לעדכן את ה-URL שהדף נושא.
  - **אינסטגרם** → `Person.sameAs`.
