## Shared rules — מה זו המשפחה

- **19 עמודים סטטיים עצמאיים.** ה-CSS מוטמע בכל עמוד (אין stylesheet משפחתי); נטענים `components/site-boot.css` ו-`site-chrome.css` (מוזרק בריצה), ובעמודי רצועת צילומים גם `triptych-gallery`/`artwork-lightbox` — עריכה שם משפיעה מחוץ למשפחה. אין renderer ואין קריאת JSON בריצה. **לא** נבנים מ-`events/artist-talk/` (אין שם artworks), **אין גנרטור** (`gen_event_pages.py` אבד) — עמוד חדש = העתקת אח.
- **תיקון רוחבי = כל 19 הקבצים, ולעתים גם אחים מחוץ למשפחה.** תקדים: `.h-title{padding-top:.2em}` בכל 19 + gala-night. לפני קומיט, harness (CLAUDE.md §7.1) **עם רוחבי המשפחה** ובאותם `--only`/`--widths` בשתי הריצות: `node tools/regress/snapshot.mjs --label before --only events/ --widths 390,769,1024,1320,1440` → שינוי → `--label after` → `node tools/regress/diff.mjs before after`. ברירת המחדל (390,1440) לא מוכיחה כלום — הפגמים ב-769–1319. diff 1 ⇒ לוודא שהשתנו רק המכוונים; ובנוסף בדיקה ויזואלית ב-769, 1024, 1320, 1440 **תמיד**.
- **בדיקה ויזואלית רק דרך http** (`python3 -m http.server`, `.claude/launch.json`; file:// חוסם `@font-face`). צילום 390 ב-headless: רוחב חלון מינימלי בכרום ~500px ⇒ דרך iframe.
